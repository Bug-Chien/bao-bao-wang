# 💣 爆爆水球大作戰

復刻爆爆王玩法的網頁遊戲：放水球炸開木箱、撿道具，把對手困進泡泡再戳破！
支援**單機（AI 對戰）**與**線上多人（最多 4 人）**，電腦與手機都能玩。

## 啟動方式

```bash
npm install
npm start
```

瀏覽器開啟 <http://localhost:3000>。

- **手機加入**：手機連同一個 Wi-Fi，瀏覽 `http://<電腦IP>:3000`（用 `ipconfig` 查 IP）。
- **純單機**：直接用瀏覽器開 `public/index.html` 也能玩單機模式（線上需啟動伺服器）。

## 操作

| 動作 | 電腦 | 手機 |
|---|---|---|
| 移動 | 方向鍵 / WASD | 左下虛擬搖桿 |
| 放水球 / 用針自救 | 空白鍵 / J | 右下 💣 按鈕 |

## 玩法

- 水球 3 秒後爆出十字水柱，可引爆其他水球（連鎖）。
- 被水柱打中會**困進泡泡**（6 秒）：被任何人碰到就出局；倒數結束也出局；有 📌 針可按放水球鍵自救。
- 炸開木箱有機率掉道具：
  - 🎈 水球+1（同時放置上限）
  - 💧 威力+1（水柱長度）
  - 👟 跑鞋（移動加速）
  - 📌 針（受困自救，可累積）
- 活到最後的人獲勝。

## 線上多人

主選單 → 線上多人 → 建立房間或加入房間 → 其他人按「準備」→ 房主選地圖並開始（2–4 人）。

## 專案結構

```
server/server.js      多人伺服器（Express + Socket.IO，伺服器權威邏輯）
public/js/engine.js   共用遊戲引擎（瀏覽器/Node 共用：移動、水球、泡泡、道具、勝負）
public/js/bot.js      單機 AI（危險區逃跑、BFS 尋路、放彈前確認逃生路線）
public/js/game.js     Canvas 渲染與遊戲主迴圈
public/js/main.js     選單 / 房間大廳 / 設定
public/js/controls.js 鍵盤 + 手機虛擬搖桿
public/js/net.js      Socket.IO 客戶端封裝
public/js/sound.js    WebAudio 合成音效（無音檔）
```

## 設定

主選單 → 設定：暱稱、音效開關（存於 localStorage）。
